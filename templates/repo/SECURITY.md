# Security policy

## Supported versions

| Version | Supported          |
|---------|--------------------|
| latest  | yes                |
| older   | no                 |

## Reporting a vulnerability

Open a private vulnerability report via GitHub Security Advisories
(`Security` tab > `Report a vulnerability`). Do not file public issues for
suspected vulnerabilities.

If you cannot use Security Advisories, email the maintainers listed in the
repo's `CODEOWNERS` file.

We aim to acknowledge reports within three working days and to ship a fix or
mitigation guidance within thirty days for critical issues.

## What to include

- A description of the vulnerability
- The affected version, commit, or release
- Proof of concept or reproduction steps
- The expected impact and any known mitigations

Coordinated disclosure is appreciated. Please give us a chance to ship a fix
before publishing.
